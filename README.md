# vaulthive

Vault filesystem hive paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/vaulthive/

## Install / run

```bash
git clone https://github.com/theworker02/vaulthive.git
cd vaulthive
node src/cli.js
node --test
```
